## ⚡ How to Ingest into Nirikshak AI Vector Store (ChromaDB)

From the root of this project:
```bash
python backend/scripts/ingest_legal_docs.py
```
Or within the running Docker container:
```bash
docker exec nirikshak-backend-vit python scripts/ingest_legal_docs.py
```
